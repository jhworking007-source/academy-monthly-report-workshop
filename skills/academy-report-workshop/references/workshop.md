# 진행 계약

## 사용자 설정
학원 운영 페이지, 작업 폴더, 대상월 YYYY-MM, 포함 재원 상태, 학생ID↔학부모 대화방 대응, 편지 말투·실제 지도 방침, 월간 실행일·시각·시간대를 저장한다. 이미 확인한 값은 재사용한다. 설정 미완료와 도구 접근 실패를 구별한다.

## 단계별 산출물
작업 폴더 안에 01 정보 맵.md, 02 업무 정의표.md, .agents/skills/*/SKILL.md, AGENTS.md, 월별 작업/<YYYY-MM>/<학생ID>/근거.json·원고.json·리포트.pdf·검수.md·승인.json·발송.json을 둔다. 실명이나 전화번호를 파일명에 쓰지 않는다. 강사용 가상 자료는 별도 실습 폴더에 둔다.
각 상태는 준비/실행중/완료/승인대기/차단/미확인으로 기록한다. 진행 현황.md에 실제 파일과 실패 사유, 재개 지점을 남긴다.

## 환경과 모델
기본 수업 권장 GPT-6.1 Sol·Medium, 복잡한 구조 오류·검수는 High. 실제 계정 선택기와 사용량을 확인한다. Plus와 API 요금은 별개이며 API 키가 필요한 이미지 스크립트를 기본 경로로 쓰지 않는다. 앱의 이미지 생성 기능과 컴퓨터 사용 플러그인 접근을 별도로 확인한다.
Windows PDF 생성은 uv/Python과 맑은 고딕을 사용한다. 실행기 선언이 필요한 패키지를 설치한다. macOS는 사용 가능한 한글 글꼴 경로를 설정하고 재검수해야 한다.

## 수업 시간의 복구
노션 접근이 안 되면 practice.md의 가상 자료로 제작 흐름을 이어가고 정보 맵 연결은 미완료로 남긴다. 카카오톡 조작이 안 되면 PDF와 발송문까지 준비하고 수동 전달을 대안으로 표시한다. 자동 발송 성공으로 집계하지 않는다. 이미지 지연 시 텍스트 흐름도와 명세를 먼저 제공하고 이미지는 대기 상태로 둔다.

## 예약
로컬 프로젝트 예약에는 켜진 컴퓨터·실행 중인 앱·접근 가능한 프로젝트가 필요하다. Windows 컴퓨터 사용은 잠금 해제와 전경 앱을 요구한다. 월간 예약은 준비·검수→승인 대기까지, 승인 후 해당 파일·수신자만 발송한다. 반복 생성에 성공해도 실제 예약 최초 실행은 별도 확인한다.
