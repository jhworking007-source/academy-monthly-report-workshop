# 만들어야 하는 실제 파일과 실행 확인

## 프로젝트 파일

- `학원 운영 설정.md`: 운영 페이지, 선택 학생 ID, 대상월, 실제 문체·지도 방침, 아직 정하지 않은 발송·일정 조건. DB ID와 속성 대응은 튜터가 실제 조회로 채운다.
- `01 정보 맵.md`: 운영 DB 구조, 원본 DB와 연결 뷰 구별, 학생→기록장→수업의 실제 연결, 조회 불가 범위.
- `.agents/skills/academy-map/SKILL.md`
- `.agents/skills/collect-records/SKILL.md`
- `.agents/skills/write-report/SKILL.md`
- `.agents/skills/plato-report-render/SKILL.md` 및 같은 폴더의 생성기·스키마·디자인 자산.
- `.agents/skills/review-report/SKILL.md`
- `.agents/skills/send-report/SKILL.md`
- `AGENTS.md`: 위 실제 이름과 인계 경로, 학생·월 공통값, 오류·기록 부족·검수·사람 승인·중복 방지·월간 시작 규칙.
- `월별 작업/<대상월>/<학생ID>/`: 근거.json, 원고.json, 내용 입력.json, 리포트.pdf, 검수.md. 학생 ID 기반 폴더명을 쓰며 연락처를 파일명에 넣지 않는다.
- `진행 현황.md`: 현재 단계와 각 산출물의 위치, 실제 실행 여부, 막힌 이유, 다음에 할 한 가지.

모든 학생의 개인정보를 설정 파일에 복사하지 않는다. 현재 학생 외 데이터는 PDF·원고에 포함하지 않는다. 학부모 수신자 정보는 관련 실행을 요청받기 전까지 ‘미설정’이면 충분하다.

## 기본안을 실제 스킬로 바꾸기

각 스킬에는 이름·언제 쓰는지·확인한 입력·실행 절차·출력 위치·예외·완료 기준을 적는다. DB와 날짜 필드 이름을 원장님에게 기술 질문으로 넘기지 않고 실제 구조에 맞춘다. 원장님의 결정과 제안은 구별해서 기록한다.

코드는 패키지 안의 검증된 PDF 생성기를 복사한다. 처음부터 생성기를 다시 쓰지 않는다. 스크립트만 복사하고 한글 글꼴·로고·스키마·필수 필드를 빼먹지 않는다. 주어진 환경에서 생성이 가능한지 확인하고 지원되지 않는다면 상태를 보류한다.

AGENTS.md에는 ‘예약 설명이 들어 있으므로 예약 완료’라고 적지 않는다. 실제 예약 도구로 등록한 결과가 있을 때만 예약 등록으로 기록한다. 실제 호출이 검증되지 않은 스킬 파일도 ‘파일 생성 / 호출 미검증’으로 구분한다.

## 실제 한 학생 실행

새 AGENTS.md와 업무별 SKILL.md를 다시 읽고, 선택한 학생·월을 유지해 해당 지침대로 수집부터 PDF 검수까지 한 번 실행한다. 파일을 만든 사실만으로 실행 성공을 주장하지 않는다.

공통 수업 기록을 학생의 근거로 사용할 때 학생 연결과 원문 범위를 남긴다. 근거마다 페이지 URL·기록 ID·원문·실제 활동일·교사 도움을 저장하고 PDF의 사실 문장에 대응한다. 없는 정보는 미확인으로 남긴다.

PDF 수치는 실제 집계만 사용한다. 상태를 알 수 없으면 null 또는 미확인으로 표현하고, 실제 0건을 확인했을 때만 0을 쓴다. full과 limited의 선택은 기록량과 템플릿 조건으로 결정하며 부족한 기록을 생성해서 채우지 않는다.

## 완료 표기

각 산출물은 다음 중 실제 상태를 적는다.

- 생성됨: 파일을 만들었지만 실행 확인은 아직 하지 않음.
- 실행 확인됨: 실제 도구 결과·생성 파일·검수 근거로 확인함.
- 사람 확인 대기: 원장님의 판단 또는 확인이 필요한 상태.
- 미설정·미검증: 이번 수업 범위 밖이거나 아직 시험하지 않음.
- 보류: 접근 오류나 필수 정보 부족으로 진행 불가.

한 학생 PDF·근거 대조표·여섯 스킬·AGENTS.md가 실제로 존재하고 PDF를 열어 확인하면 수업 결과를 전달한다. 발송은 하지 않았고 예약은 등록하지 않았다는 실제 상태를 함께 남긴다. 대화 내용의 학생·월·설정과 파일이 서로 일치해야 한다.

## 다음 실행 문구

“이 프로젝트의 AGENTS.md와 업무 스킬을 읽고, 내가 선택하는 학생 한 명의 월간 리포트를 만들어줘. 학생과 대상월 중 아직 정하지 않은 것만 하나씩 물어봐줘. 원본 기록과 PDF를 대조한 뒤 결과를 열어줘. 이번에는 발송하거나 예약을 등록하지 마.”

다음 학생으로 바뀌면 이전 학생의 원고와 PDF를 새 학생 입력으로 재사용하지 않는다. 새 학생 ID로 자료를 다시 수집한다.

파일 열기 도구가 queued를 반환하면 화면에 이미 표시됐다고 단정하지 않는다. 열기 요청 상태와 클릭 가능한 실제 파일 경로를 함께 보여주고, 원장님의 확인을 파일 열기 요청 성공으로 대신하지 않는다.
