# 실제 흐름 시각화


먼저 다음 요청으로 이미지 입력 자료를 만든다.

```text
현재 프로젝트의 실제 SKILL.md, AGENTS.md, 단계별 산출물과 실행 이력을 읽고 나의 월간 리포트 흐름 명세를 작성해줘.
노드마다 단계 이름·입력 파일 종류·출력 파일 종류·현재 상태를 적고 화살표와 분기 조건을 모두 나열해줘.
기록 부족/조회 실패, 원장 승인/보류, 발송 완료/실패/미확인을 포함해줘.
아직 실행하지 않은 단계는 미검증, 승인 전은 승인 대기로 적어줘.
학생 실명·연락처·작품 원문은 제거하고 단계와 파일 종류만 남겨줘.
내가 만든 실제 파일과 다르면 명세를 먼저 수정해줘.
```

검증한 명세 파일과 다음 프롬프트를 함께 이미지 생성 도구에 전달한다. 이는 입력 첨부를 요구하는 완성 프롬프트이며 가짜 실행 결과를 채워 넣는 양식이 아니다.

> 학원 원장님이 자기 월간 리포트 시스템을 이해하도록 돕는 16:9 가로 인포그래픽을 제작한다. 함께 첨부한 검증된 흐름 명세를 유일한 내용 정본으로 사용한다. 명세의 단계 이름과 상태 문구를 글자 그대로 넣고, 그 안에 존재하는 모든 노드와 연결·분기만 그린다. 기본 읽기 방향은 왼쪽 위에서 오른쪽으로, 다음 줄로 이어지는 방식이다. 월간 예약은 시작 노드에 연결한다. 정보 맵, 기록 수집, 원고, PDF, 검수, 원장 승인, 카카오톡 발송, 결과 기록은 명세에 있는 순서대로 배치한다. 기록 부족은 안내·제안 원고 분기, 조회 실패는 보류 분기로 구별한다. 원장 승인 이전에는 발송으로 이어지는 우회선을 만들지 않는다. 완료에는 체크 아이콘과 “완료”, 승인 대기에는 사람 아이콘과 “승인 대기”, 미검증에는 빈 원과 “미검증”을 명세에 맞게 붙인다. 흰 배경, 차콜 글자, 구조는 청록 #006B73, 연한 면은 #B8D6D8, 사람의 승인 관문은 절제된 주황과 사람 아이콘으로 구별한다. 승인된 MAKE Y 템플릿의 간결한 선과 일러스트 스타일에 맞춘다. 제목과 로고는 이미지에 넣지 않는다. 바깥 안전 여백 8%, 노드 사이 충분한 간격, 한글은 크게 또렷하게 배치한다. 학생 이름·연락처·작품 원문·실제 앱 화면·임의 수치·추가 업무·워터마크는 넣지 않는다. 완료하지 않은 단계를 완료로 표시하지 않는다.


실행 이력에서 사실로 확인된 상태만 사용한다. imagegen 접근 불가면 텍스트 명세를 보존하고 미완료로 보고한다.
