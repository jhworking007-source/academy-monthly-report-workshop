# 학생별 원고와 원장 편지

입력: 근거.json, 결측 목록, 원장님의 문체·지도 방침, PDF 입력 형식.
관찰 사실·근거 범위의 해석·다음 지도 제안을 구별한다. 평가 문장마다 근거ID와 도움 조건을 내부 대조표에 연결한다. 없는 성취·감정·상담을 채워 넣지 않는다.
기록 부족은 매번 상황에 맞는 일반 안내·가정 대화 제안을 작성하되 학생의 관찰 사실처럼 쓰지 않는다. 비교 가능한 같은 활동의 첫 글/재작성에만 변화 표현을 사용한다.
원장 편지는 감사→확인한 장면→다음 지도→가정 대화→소통 안내와 서명 순서 5문단. 실제 교육 방침과 약속을 원장이 검토할 수 있게 한다.
결과: 원고.json과 문장별 근거표. plato-report-render의 내용 입력.json과 항목 목록을 읽고 모든 학생별 값을 교체한다. student_name/class_label/report_month를 지정하고 dates·works·counts를 대조한다.
full은 대표 관찰4건, 비교 작품이 records[0]/records[2]에 놓이는 현재 템플릿 제약이다. 부족하거나 비교 불가면 limited를 사용하며 기본 입력의 예문을 다른 학생의 사실로 재사용하지 않는다.
완료: 근거 없는 평가가 없고 현재 입력값과 대상 학생·월이 일치한다. 원고가 넘치면 핵심 의미와 근거를 유지해 축약한다.
