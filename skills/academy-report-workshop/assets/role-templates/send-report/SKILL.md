# 카카오톡 승인 후 전달

입력: 검수 통과 PDF, 승인.json, 학생ID·대상월·정확한 대화방 대응, 발송 이력.
동일 학생ID+대상월의 완료 이력이 있으면 중복 발송을 중단한다. 미확인 이력이 있으면 먼저 원래 전송 화면을 확인한다. 새 파일·수신자로 바뀌면 재승인을 받는다.
컴퓨터 사용 도구로 실제 카카오톡 앱을 연다. Windows에서 대상 앱을 전면에 두고 사용자가 같은 세션을 동시에 조작하지 않도록 안내한다. 표시 이름만으로 학부모를 추측하지 말고 원장이 확인한 식별정보와 대화방을 대조한다.
첨부 PDF 또는 접근이 확인된 다운로드 링크를 준비한다. 승인 범위의 수신자·파일 해시와 일치하는 경우 전송한다. 오늘 수업에서는 지침만 만들고 발송하지 않는다. 나중에 원장님이 한 학생의 실제 전달을 요청하면 확인한 수신자 한 명으로만 진행한다. 본인에게 테스트할지 실제 수신자에게 보낼지도 원장이 선택하며 임의로 확대하지 않는다.
전송 후 메시지/파일이 대화방에 표시되는지 실제 화면을 확인한다. 이것을 학부모가 읽었다는 의미로 보고하지 않는다.
결과: 발송.json에 학생ID·대상월·파일해시·대화방 식별정보·전송시각·완료/실패/미확인·근거를 기록한다. 화면 불명확/도구 중단이면 미확인으로 남기고 자동 재전송하지 않는다.
완료: 실제 전송 확인 또는 보류 사유가 기록된다. 원장 승인 없이 발송하지 않는다.
