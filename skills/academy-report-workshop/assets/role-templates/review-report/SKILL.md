# PDF 근거와 레이아웃 검수

입력: 근거.json, 원고.json, PDF, 대상 학생ID·월·예정 수신자.
PDF 전 페이지를 렌더해 실제 크기로 확인한다. 학생·월·머리말·작품 날짜·교사 도움·원장 편지·페이지 순서를 원고와 대조한다. 관찰 지도 날짜/점과 records.domains, 부족형 숫자/막대를 counts와 대조한다.
겹침·잘림·작은 글씨·깨진 한글을 확인한다. 가상자료 여부는 내부 근거와 강의 설명에 남기고 PDF에는 제작용 시안 문구를 넣지 않는다.
결과: 검수.md에 내용/레이아웃 판정과 수정 지점, PDF SHA-256, 대상 학생·월·수신자. 오류면 원고/제작 단계로 되돌린다.
완료: 검수 통과 후 원장님에게 PDF와 수신자를 열어 보여준다. 검수 통과는 발송 승인이 아니다. 원장의 실제 승인 메시지가 있어야 승인.json에 학생ID·월·PDF해시·수신자·승인시각을 기록한다.
