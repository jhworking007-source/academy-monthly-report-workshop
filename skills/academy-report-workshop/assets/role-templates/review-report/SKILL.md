# 원장 검토를 위한 PDF 확인

입력은 학생 ID·월, 근거.json, 원고.json, PDF다. PDF 제작만 요청된 경우 학부모 대화방이나 연락처는 요구하지 않는다.

PDF 전 페이지를 실제 크기로 열어 학생·월·작품 날짜·교사 도움·편지·페이지 순서·기록 수를 원고와 대조한다. 다른 학생의 정보, 근거 없는 성장 주장, 수업 전체 관찰을 학생 개인 수행으로 바꾼 문장이 없어야 한다. 관찰 지도는 기록 존재를 뜻하며 점수가 아니다.

겹침·잘림·작은 글씨·한글 깨짐을 확인한다. 잘못된 문구는 근거와 의미를 지키며 고치고 PDF를 다시 만든다. 검수.md에 실제 확인한 항목, 보류한 항목, PDF 버전·해시를 적는다.

완료되면 원장님에게 PDF를 열어주고 사실과 지도 방향을 확인하도록 안내한다. 검수 통과나 내용 확인은 외부 발송 승인이 아니다. 발송을 별도로 요청받은 경우에만 수신자와 최종 파일을 추가 대조하고 해당 항목의 명시적 승인을 받는다.
