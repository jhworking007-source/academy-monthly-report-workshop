# 학원 월간 리포트 AI 튜터

0.2.0 · 실제 학생 한 명을 위한 4주차 대화형 실습 패키지

skills/academy-report-workshop 전체 폴더를 설치합니다. PDF 생성기·빈 입력 구조·로고·6개 업무 스킬 기본안이 포함되어 있습니다. 가상 학생 데이터는 포함하지 않습니다.

튜터는 학원 운영 페이지를 읽고 학생과 대상월을 하나씩 확인합니다. 질문에 답하면서 학원에 맞는 스킬 6개와 AGENTS.md를 만들고, 한 학생의 실제 기록으로 PDF와 근거표를 작성합니다. 학생 페이지 안의 별도 기록장과 공통 수업 DB를 구별합니다.

기록이 적거나 없으면 확인된 범위와 다음 지도 계획을 담는 안내형을 사용합니다. 개인 성장·출석·작품을 지어내지 않습니다. 조회 실패는 기록 0건으로 처리하지 않습니다. 기본 실습은 PDF 확인까지이며 발송과 예약 등록은 실행하지 않습니다.

## 설치 후 시작

academy-report-workshop 스킬을 읽고 우리 학원의 실제 학생 한 명으로 월간 리포트 만들기를 시작해줘. 쉬운 질문을 하나씩 해주고 스킬 6개·AGENTS.md·PDF를 만들어 보여줘. 오늘은 발송과 예약 등록은 하지 마.

앱에서 스킬 선택이 보이지 않으면 새 대화에서 확인하거나 설치된 SKILL.md 경로를 직접 지정합니다. 파일 설치와 앱의 자동 발견 여부는 구분합니다.

## 실행 조건

Windows의 Python 3.11 이상, uv, 맑은 고딕을 사용합니다. Adobe 플러그인은 필요하지 않습니다. 다른 OS의 한글 글꼴 경로는 별도 검증이 필요합니다. Notion 연결은 원장님의 운영 페이지 읽기 권한이 있어야 합니다. 설치에 Notion Business의 AI 검색이나 여러 DB 동시 쿼리를 요구하지 않습니다.

독립 에이전트로 실제 기본 Notion의 한 학생·한 달을 읽어 안내형 PDF 4쪽, 스킬 6개와 AGENTS.md를 생성·검수했습니다. 개인 기록이 없는 사례의 검증이며 충분한 개인 기록·작품 비교가 있는 사례의 전체 실행, 모든 Plus 계정/OS, 실제 발송·예약 성공을 보장하는 검증은 아닙니다.

플라톤 로고는 사용자 요청 리포트 템플릿의 브랜드 자산입니다. 플라톤 공식 배포물이 아닙니다. 실제 학생 정보·Notion 조회 결과·검수 PDF는 이 공개 저장소에 포함하지 않습니다.
