# 학원 월간 리포트 실습

2026년 10월 학원 원장님 대상 AI 실무 4주차를 위한 AI 강사형 스킬 배포 준비본입니다.

- 설치 스킬: skills/academy-report-workshop
- 호출 이름: academy-report-workshop
- 강사가 설명한 흐름을 따라 정보 맵과 업무별 스킬·AGENTS.md를 만들고, 중간 결과를 직접 확인합니다.
- PDF 생성기는 Windows에서 검증했습니다. Notion·카카오톡·예약의 전체 실행은 수업 전 계정과 기기에서 별도 리허설해야 합니다.
- 포함된 작품과 기록은 가상 실습 자료이며 실제 학생 기록이 아닙니다. 실제 운영에는 검증한 학생별 원고를 넣습니다.
- Adobe 플러그인은 필요하지 않습니다. Python/uv와 한글 글꼴이 필요합니다.
- PDF는 제작용 표식 없이 생성되며 실제 학부모 발송은 원장 확인·승인 후에만 진행합니다.
- 플라톤 로고는 리포트 템플릿 시연을 위한 브랜드 자산입니다. 이 저장소를 플라톤의 공식 배포물로 소개하지 않습니다.

이 버전은 수업 리허설용 0.1.1입니다. 설치·생성 파일 존재를 전체 자동화 성공으로 해석하지 않습니다.
